# Сервис знаний «Наставника»

Этот каталог содержит FastAPI backend для поиска по утверждённым документам
и ответа с проверяемым источником. Клиент MAX и управление обучением находятся
в корне репозитория. Самостоятельный веб-интерфейс здесь не используется.

Образ собирается из этой папки:

```sh
docker build -f services/knowledge/Dockerfile.max-pilot -t nastavnik-knowledge:local services/knowledge
```

Миграции Alembic применяются при запуске контейнера. Для рабочего ответа
требуются PostgreSQL, подготовленная модель поиска BGE-M3 и настроенный
генератор. Секреты и документы нельзя помещать в образ. Общий локальный
запуск описан в [инструкции для проверяющего](../../docs/contest/START.md).

Внутренние пути API, имена таблиц и переменных окружения пока сохраняют
совместимость с действующим стендом. Переименовывать их без согласованной
миграции двух сервисов и баз нельзя.
