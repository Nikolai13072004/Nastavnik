# Prodigy в MAX

Обновлено 26 сентября 2026 года. Это конкурсный пилот, не коммерческий релиз.

## Работает

- Бот и Mini App открываются по HTTPS. Сотрудник связывает MAX с Prodigy, видит назначенные курсы, читает материалы, проходит тест. Результат сохраняется.
- HR-экран позволяет добавить сотрудника, назначить курс, опубликовать документ и посмотреть прогресс. Новая редакция запускает повторное ознакомление и проверку знаний. Серверные сценарии проверены, телефонный HR-сценарий пока нет.
- Поиск цитат работает для материалов доступного курса.
- Для демо-курса «Первый день: обучение в MAX» включён AI по утверждённому учебному документу. Vedomo работает в отдельном стеке на VPS, проверяет сервисный ключ и курс. Prodigy проверяет назначение, версию документа и каждый источник ответа.

## Проверено

- Ответ AI с источником прошёл через публичный HTTPS-маршрут MAX от имени привязанного тестового сотрудника. Другой курс получил отказ, запрос без сессии отклонён.
- Утверждённый документ в Prodigy и Vedomo имеет одинаковый SHA-256. Сервисный ключ не попал в репозиторий. Веб-вход LMS снаружи закрыт.
- Целевые тесты MAX: 14 из 14; проверка типов, lint и Docker-сборка прошли. На временной базе ранее проверены права HR, чужая организация, отзыв документа и повторное обучение.
- Свежая копия PostgreSQL восстановлена в отдельном временном контейнере. Число курсов, привязок MAX и документов совпало с рабочей базой. Рабочий контейнер не перезапускали.
- Копия Vedomo восстановлена отдельно: база содержит документ, индекс - два фрагмента, файл документа сохранил исходный SHA-256. Архивы лежат на VPS и на компьютере вне репозитория. После проверки публичный запрос AI снова прошёл.
- Модель остаётся загруженной в память. После прогрева ответ занял около 8 секунд; первый запрос после запуска занял около 86 секунд. Таймауты настроены на такой случай. На VPS оставалось около 8 ГБ доступной памяти и 91 ГБ диска при последней проверке.

## Локальная проверка 26 сентября

- На компьютере проверены свежие сборки Prodigy и Vedomo, миграции двух пустых PostgreSQL и создание демо-курсов. Prodigy: 752 unit-теста, типы и целевой lint прошли. Vedomo: 749 тестов прошли, 4 пропущены; есть предупреждение Starlette/AnyIO. Проверены HTTP 200 и отказ без ключа, но настоящие модели в локальном контуре не подключались.
- В Prodigy шрифты теперь локальные; сборка не обращается к Google Fonts. Vedomo собирается без частного базового образа, CPU-образ занимает 2,74 ГБ вместо прежних 11 ГБ. Рабочий VPS в этой пачке не обновлялся.
- Исправлен пропуск уведомления о новой редакции при нескольких получателях: права проверяются для адресата сообщения. Регрессионный тест воспроизвёл ошибку до исправления; после него прошли все 194 infra-теста на отдельной PostgreSQL. Исправление пока в конкурсной ветке, не на VPS.

## Осталось

- Проверить новый блок AI и HR-экран на телефоне. Для HR нужен второй аккаунт MAX, который владелец предоставит позже.
- Прогнать конкурсную демонстрацию целиком на телефоне. Восстановление копии Vedomo проверено, но сам стенд из этой копии не поднимали.
