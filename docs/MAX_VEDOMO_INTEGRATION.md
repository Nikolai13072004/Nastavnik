# Vedomo для MAX

На конкурсном VPS Vedomo развёрнут отдельно от Prodigy. Генеративный AI включён только для курса `max-pilot-onboarding-course` организации `max-pilot-demo-org`. Остальные курсы продолжают использовать обычный поиск цитат.

Учебный документ `onboarding-policy.md` утверждён владельцем и опубликован в обеих системах с одинаковым SHA-256. Сервисный ключ ограничен одной организацией, одним курсом и отдельным workspace. Ключ находится только в закрытом окружении Prodigy, его хеш - в Vedomo. Ключ сменён 26 сентября 2026 года, старый отозван. Срок нового ключа - 30 дней; его нужно обновить до истечения.

Prodigy перед ответом проверяет привязку MAX, назначение, публикацию курса и текущую версию документа. После ответа он сверяет каждый источник с разрешённым текстом. Vedomo проверяет источники по индексу. Это защищает от выдачи чужого документа, но не гарантирует безошибочность вывода модели.

## Новый документ

Путь установлен на VPS 26 сентября. Обновлены Prodigy, backend Vedomo и правила собственных gateway. Схема БД и сервисный ключ сохранены. Подключение и отказы доступа проверены через публичный HTTPS.

1. HR загружает утверждённый `.txt` или `.md` в курс, проверяет текст и публикует документ. PDF пока доступен только для чтения.
2. В «Проверить текст» HR скачивает текст для AI и передаёт администратору. Администратор загружает этот файл в выделенный workspace Vedomo и ждёт статуса `ready`. Используется подготовленный текст, а не исходный файл: Prodigy нормализует переносы строк, BOM и крайние пробелы при загрузке.
3. HR нажимает «Подключить к AI». Сервер находит единственный готовый источник с тем же SHA-256, повторно проверяет права, публикацию и версию курса, затем сохраняет подключение и запись аудита. Черновик, отозванный документ, чужой курс и неоднозначный источник не подключаются.
4. Проверить ответ с источником, отсутствие доступа к другому курсу и запрос без сессии. Только после этого открывать AI в интерфейсе.

Автоматическая загрузка из MAX в Vedomo пока не реализована. Сервисный API остаётся только для чтения и ответов. Проверка скачивания в обычном браузере не заменяет проверку в MAX.

Для закрытого администрирования остаётся команда `npx tsx scripts/max-knowledge-mapping.ts approve --course-id <id> --course-document-id <id> --vedomo-document-id <id> --vedomo-document-hash <sha256>`.

При отзыве выполнить `npx tsx scripts/max-knowledge-mapping.ts revoke --course-id <id> --vedomo-document-id <id>` и убрать документ из Vedomo. Пока тестовый AI не нужен, его можно закрыть через `MAX_VEDOMO_ENABLED=false` с пересозданием только web-сервиса Prodigy.
