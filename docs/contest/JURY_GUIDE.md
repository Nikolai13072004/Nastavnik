# Проверка «Наставника» в MAX

Основной сценарий: сотрудник изучает вводный материал, получает ответ AI
с источником и проходит тест. HR видит сохранённый результат.
В стенде только вымышленные данные, это демонстрация, не рабочая организация.

## Что потребуется

- Аккаунт в MAX на телефоне или компьютере.
- Для проверки обеих ролей — два разных аккаунта MAX. Один аккаунт нельзя
  привязать сразу к профилям HR и сотрудника.
- Бот [«Наставник» — @se14424319_bot](https://max.ru/se14424319_bot).

Отдельно регистрироваться в веб-LMS не нужно. Приложение открывается из MAX:
прямая ссылка на его веб-адрес не передаёт данные для входа.

## Коды для жюри

| Роль | Одноразовый код |
| --- | --- |
| HR | `uv8ct-jlbVrpz74zf8aSyYE0tEsFVRCA` |
| Сотрудник | `NcKP6OqxK-j7a6LvUGdcWGpF8fiBYo_R` |

Коды действуют до **28 декабря 2026 года, 18:17 МСК**. Каждый код можно
использовать **один раз для одного аккаунта MAX**. После привязки профиль
сохранится: окончание срока кода не отключит уже вошедшего проверяющего.
Так как этот репозиторий публичный, код может оказаться занятым до начала
проверки. В таком случае попросите команду выдать новый через контакт в
конкурсной заявке. Для нескольких проверяющих нужны отдельные коды;
передавать уже использованный код следующему человеку бесполезно.

## Первый вход — по шагам

1. Откройте [бота «Наставник»](https://max.ru/se14424319_bot) в MAX и нажмите
   «Начать» или отправьте `/start`.
2. Нажмите синюю кнопку **«Открыть»** внизу чата. Если её не видно, отправьте
   `/start` ещё раз и выберите открытие приложения из нового меню.
3. В Mini App найдите поле **«Одноразовый код привязки»**. Скопируйте код своей
   роли из таблицы выше, вставьте в поле и нажмите **«Связать профиль»**.
   Не отправляйте код обычным сообщением боту.
4. Дождитесь основного экрана. Сотрудник увидит назначенные курсы, а HR —
   раздел **HR**. Если поле кода больше не появляется, профиль уже связан;
   повторно вводить код не нужно.
5. Для проверки другой роли войдите с **другого аккаунта MAX** и повторите
   шаги с другим кодом. Кнопки переключения ролей в одном профиле нет.

Сотруднику заранее назначен курс «Первый день сотрудника в MAX». Внутри
приложения можно читать материалы, спрашивать AI, открывать документы-источники
и проходить тест. HR видит обучение своей учебной организации и результаты.

Если HR хочет подключить ещё одного учебного сотрудника, он открывает свой
раздел в Mini App, создаёт карточку,
назначает курс и передаёт показанный код адресату. После ввода кода MAX
связывается с карточкой. HR может перевыпустить истёкший код, пока профиль
ещё не связан.

## Основной сценарий

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Открыть бот, нажать «Открыть», ввести код сотрудника из таблицы выше | Профиль связан, курс виден в списке |
| 2 | Открыть «Первый день сотрудника в MAX», прочитать материал, подтвердить «Изучено» | Материал отмечен изученным |
| 3 | Спросить AI: «Что делать, если код привязки потерян?» | Ответ предлагает обратиться к HR или администратору; есть источник |
| 4 | Раскрыть источник, нажать «Читать документ» | Открывается именно документ из ответа |
| 5 | Пройти тест из трёх вопросов по материалу | Сохраняются результат и попытка; для сдачи нужны три верных ответа |
| 6 | Закрыть Mini App и открыть снова | Материал и результат остаются сохранёнными |
| 7 | Из другого аккаунта MAX открыть Mini App, ввести код HR, перейти в раздел HR, выбрать курс и отчёт | Видны назначение и результат сотрудника |

Тест общего демо-курса можно повторять после сдачи. История и лучший результат
сохраняются. Это правило не отменяет ограничения других курсов.

## Дополнительная проверка

В чате отправить `/start` или «Меню», выбрать общий курс, спросить AI
и нажать «Прогресс». Результат совпадает с Mini App. Короткий тест также можно
пройти в чате; «Продолжить позже» сохраняет ответы на время паузы до 30 минут.

Документы загружает HR. Проверку загрузки, публикации и оригиналов проводить
на отдельном учебном документе, не заменять источник основного показа.
Подробности: [сценарий HR](../MAX_DEMO.md#hr).

В HR можно открыть историю попыток, ошибки по вопросам и статистику AI.
Она показывает реальные запросы и рассмотренные жалобы, а не заявленную
точность модели. [Проверка качества ответов](AI_QUALITY_EVIDENCE.md)
содержит отдельный небольшой набор вопросов и его ограничения. Обычная
переписка сотрудника HR недоступна.

## Если что-то не работает

| Ситуация | Действие |
| --- | --- |
| «Откройте приложение из MAX» | Вернуться в чат бота и нажать «Открыть» |
| Код истёк или уже использован другим аккаунтом | Попросить новый личный код у команды через контакт в конкурсной заявке |
| Профиль связан, курс не виден | Команда проверяет назначение; затем нажать «Проверить новые курсы» |
| В чате нет меню | Отправить `/start` или «Меню» |
| AI ограничил частоту запросов | Подождать минуту и повторить; обучение и тесты доступны |
| AI отказал без источника | Это предусмотренный отказ при недостатке подтверждённых данных, не успешный ответ по документу |
| AI или сеть недоступны | Зафиксировать ошибку и сообщить команде; не подменять живую проверку заранее сохранённым ответом |
