# Материалы для проверки

Этот каталог относится к конкурсному пилоту «Наставник». Код приложения,
сервиса знаний и запуска хранится в одном репозитории. Сначала прочитайте
[запуск из исходников](START.md) и [пошаговую проверку](JURY_GUIDE.md).

`openapi.json` описывает основные MAX API, `DATA-API.yaml` - данные по полям
задания, `test-data.json` содержит только вымышленные учебные примеры. Точный
формат загрузки на платформу организаторов ещё нужно сверить перед сдачей.
Финальный commit hash, видео и PDF-презентация пока не зафиксированы.

После финального коммита `python scripts/package-max-source.py` создаёт один
архив `nastavnik-source-<commit>.zip`, файл SHA-256 и внутренний манифест.
Скрипт откажется упаковывать незакоммиченные изменения, локальные секреты,
базы и кеши. До фиксации версии можно выполнить безопасную проверку состава:
`python scripts/package-max-source.py --check`. Архив и контрольную сумму
передают организаторам вместе, не меняя их после отправки.

На текущем стенде Mini App открывается из
[бота MAX](https://max.ru/se14424319_bot). Прямой переход на веб-адрес не
передаёт подписанные данные MAX. Демонстрационная пара кодов для жюри и
инструкция по входу указаны в [гайде](JURY_GUIDE.md). Другие коды, токены и
`initData` в Git не добавляйте.

## Что проверить

1. Сотрудник входит по личному коду, открывает назначенный курс и материал.
2. Задаёт вопрос по учебному документу, раскрывает источник и открывает
   именно этот документ.
3. Проходит и повторяет тест, видит сохранённый прогресс.
4. HR видит результаты, загружает документ и проверяет его публикацию.
5. Чужой пользователь и сотрудник без назначения не получают закрытый
   документ или HR-отчёт.

Ответ с отказом и без источников означает, что подтверждённых сведений не
хватило. Это не доказательство точности на любых документах. Рабочие базы и
внутренний сервис знаний не публикуются в интернет.
