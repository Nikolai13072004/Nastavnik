# Шрифты интерфейса

IBM Plex Sans, IBM Plex Mono и Onest взяты из Google Fonts:
https://github.com/google/fonts/tree/23e54b51ddffbc7713c583748e3bd86f62b1fa4a/ofl.
Лицензии SIL OFL находятся рядом с файлами.
Исходные TTF сжаты в WOFF2 через FontTools, без изменения глифов и набора символов.

Шрифты подключены через `next/font/local`, поэтому сборка не зависит от Google
Fonts API. Сохранены семейства, кириллица и CSS-переменные интерфейса. При обновлении
заменять файлы вместе с лицензиями и проверять отображение русского текста.
