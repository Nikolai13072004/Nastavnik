# Наставник

Наставник помогает сотруднику учиться в MAX: открыть назначенный курс, прочитать
материал, задать вопрос по утверждённому документу и пройти проверку знаний.
HR создаёт карточку сотрудника, выдаёт личный код для первого входа, назначает
обучение и видит результаты.

Это конкурсный пилот с вымышленными данными, не готовая система для загрузки
конфиденциальных документов компании.

## Как проверить

1. Откройте [бота в MAX](https://max.ru/se14424319_bot) и нажмите «Открыть».
2. Получите личный код у HR или администратора стенда и введите его в Mini App.
3. Пройдите [сценарий для проверяющего](docs/contest/JURY_GUIDE.md).

Обычная ссылка на Mini App в браузере не передаёт подписанные данные MAX и не
заменяет вход через бот. Имя бота «Наставник» отправлено на модерацию MAX;
до её завершения в поиске может показываться прежнее имя. Адрес бота не менялся.

## Исходники и запуск

В этом репозитории находятся обе части конкурсного решения:

- `src/app/max`, `src/app/api/max`, `src/modules/max` - бот, Mini App и API обучения;
- `services/knowledge` - сервис поиска и ответов по документам;
- `deploy/max` - Docker-конфигурация, проверка и инструкции для стенда.

[Запуск из исходников](docs/contest/START.md) собирает обе части одной командой
Docker Compose. Нужны Docker с Buildx, Python и заранее подготовленная модель
поиска BGE-M3. Ключ GigaChat, токен бота и другие секреты хранятся вне Git.
Текущий пилот использует отдельные PostgreSQL для обучения и сервиса знаний.

При локальной проверке `deploy/max/create-review-env.py --joint` создаёт
закрытый файл настроек. Compose публикует только проверочный веб-порт
`127.0.0.1:53100`; базы данных и сервис знаний доступны лишь внутри Docker.
Запуск применяет миграции, загружает учебный документ и проверяет сценарий
без настоящего MAX и GigaChat. Ожидаемые строки успеха и команда остановки
приведены в [инструкции](docs/contest/START.md). Для реального стенда нужны
действующие ключи MAX и GigaChat, HTTPS и отдельная проверка двух ролей.

Для разработки клиентской части на Windows используйте `npm run dev:safe`,
а не прямой запуск Next.js. Требования и ограничения описаны в [AGENTS.md](AGENTS.md).

Ответ AI выдаётся только по разрешённым опубликованным документам. Наличие
источника не означает безошибочности ответа; качество проверяется отдельным
набором вопросов, а реальные материалы компании требуют отдельной приёмки.
Повторный вход, мобильный клиент MAX и роли проверяются на вымышленных
профилях до конкурсного показа.
